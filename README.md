# Benim Sayfam — GitHub Pages

Bu klasör, `spinemrullah.github.io` için hazırlanmış mobil uyumlu kişisel tanıtım sitesidir.

## Yayına alma
1. GitHub'da `spinemrullah.github.io` adında **Public** bir repository oluştur.
2. Bu klasördeki `index.html` ve `README.md` dosyalarını repository'nin kök dizinine yükle.
3. Repository → **Settings → Pages** bölümünde **Deploy from a branch** seç.
4. Branch olarak `main`, klasör olarak `/ (root)` seçip **Save**'e bas.
5. Yayın adresi: https://spinemrullah.github.io

`index.html` dosyasındaki metinleri, proje kartlarını ve iletişim bağlantılarını kendine göre düzenleyebilirsin.
